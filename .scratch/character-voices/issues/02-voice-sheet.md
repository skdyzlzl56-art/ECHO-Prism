# 02: 캐릭터 말투 시트

**What to build:** 모든 캐릭터의 성별·말투·성격·참고 분위기를 CHARACTERS.md와 GLOSSARY.md에 정리해, 이후 대사 개편의 기준이 되게 한다. 헥사만 남성, 나머지(루미·화가·시계지기·글리치·침묵·사서·???/리라 포함)는 모두 여성. 참고 분위기는 말투의 결만 참고하고 원작 대사는 베끼지 않는다: 루미=유이하가마 유이, 헥사=고도 검사, 화가=다크소울 화방녀, 시계지기=동방 사쿠야, 글리치=오레이모 키리노, 침묵=프리렌. 캐릭터마다 예시 대사 3줄과 호칭·종결어미 규칙을 적는다. 스킬 `character-management`를 사용한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
