# 01: 쿨타임 원

**What to build:** 대시 쿨타임은 주인공 주위에 원으로, 회복·방패·특수기 쿨타임은 지금 곁에 있는 보조 캐릭터 주위에 원으로 보인다. 원이 차오르다 다 차면 준비됐음을 알 수 있어, 글자를 읽지 않고도 쿨타임이 직관적으로 보인다. 오른쪽 패널의 쿨타임 글자 줄은 원으로 대체한다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 대시 쿨타임 원이 주인공 주위에 표시되고 차오른다
- [ ] 회복·방패·특수기 원이 곁에 있는 보조 캐릭터 주위에 표시된다 (교대하면 새 캐릭터 기준)
- [ ] 준비 완료 상태가 눈에 띄게 구분된다
- [ ] 원의 비율(0~1) 계산은 sim 쪽 테스트로 검증하고, 화면 연출은 브라우저 미검증으로 보고에 명시
- [ ] 글자 쿨타임 줄 제거, npm test 통과
