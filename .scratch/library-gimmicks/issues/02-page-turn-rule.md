# 02: 쪽 넘김 규칙 (pageRule)

**What to build:** 전투 설정 옵션 `pageRule`. 안전 구역이 판 전체의 좌우 반쪽이 아니라 쪽번호 위치의 좁은 세로 띠다. 주기마다 경고 후 띠가 책장 넘기듯 옆으로 이동하고, 띠 밖에 있으면 피해를 입는다. 판 분할 규칙(`splitRule`)과 겹치지 않게 구현한다. 옵션 파라미터, 경고 표시, 화면 연출, 테스트, GLOSSARY 항목까지 한 번에 끝낸다.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 경고 → 넘김 → 안전 띠 이동이 주기마다 일어난다
- [ ] 띠 밖에서는 피해, 띠 안에서는 피해 없음
- [ ] 옵션이 없는 전투는 동작이 달라지지 않는다
- [ ] `phaseRules`로 페이즈별 켜고 끌 수 있다
- [ ] 테스트는 새 `*.test.js`에 둔다
- [ ] GLOSSARY.md에 **쪽 넘김 규칙** 추가
- [ ] 화면 효과는 브라우저 미확인 시 보고서에 적는다
