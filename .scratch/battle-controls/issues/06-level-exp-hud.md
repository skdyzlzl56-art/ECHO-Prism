# 06: 레벨과 경험치 표시

**What to build:** 전투 화면 아래쪽에 레벨(Lv.)과 경험치 바를 표시한다. 경험치는 페이즈를 돌파할 때마다 지급되고, 경험치가 가득 차면 레벨이 오른다. 패배 후 재도전하면 그 전투에서 모았던 경험치는 이어지지 않고 전투 시작 시점의 값으로 돌아간다. 승리하면 모은 경험치가 유지되어 다음 전투로 이어진다. 레벨은 표시만 하고 전투 능력에는 영향을 주지 않는다.

기본값(조정 가능): 페이즈 돌파당 경험치 +20, 레벨당 필요 경험치 100(레벨 업 시 초과분은 이월), 시작 Lv.1.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 페이즈 돌파 시 경험치가 오르고 레벨 업 때 레벨이 오른다 (sim 테스트)
- [ ] 패배 후 재도전하면 그 전투에서 얻은 경험치가 사라진다 (sim 테스트)
- [ ] 승리 후 다음 전투에서 경험치와 레벨이 이어진다
- [ ] 기존 조작 안내 문구와 겹치지 않는다
- [ ] `npm test` 통과
