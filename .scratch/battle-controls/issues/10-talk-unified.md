# 10: 전투 중 대화도 스토리 대화와 같은 조작/로직

**What to build:** 전투 중 대화(페이즈 대사)가 스토리 장면 대화와 같은 입력 규칙과 같은 진행 로직을 쓴다. 스토리 대화에서 되는 조작(Ctrl 누르고 있는 동안 빠르게 넘기기, X로 빨리 출력, 타이핑 중 키를 누르면 즉시 완성)이 전투 대화에서도 똑같이 된다. 대사 출력 속도, 완성/다음 대사 넘김, 조작 키의 정의를 한 곳에 두어, 이후 키를 바꾸거나(07) 규칙을 고칠 때 두 곳이 어긋나지 않게 한다.

**Blocked by:** 05 (X 빨리 출력)

**Status:** ready-for-agent

- [ ] 전투 대화에서 Ctrl을 누르고 있는 동안 스토리 대화와 같은 방식으로 빠르게 넘어간다
- [ ] 전투 대화에서 X를 누르고 있으면 글자가 빠르게 출력되고, 대사는 넘어가지 않는다
- [ ] 전투 대화와 스토리 대화의 타이핑 속도, 완성/넘김 동작이 같은 로직에서 나온다 (중복 구현이 남지 않는다)
- [ ] 스토리 대화의 기존 동작은 바뀌지 않는다
- [ ] `npm test` 통과
