# 03: 대시 (X키)

**What to build:** 전투 중 X를 누르면 현재 이동 방향으로 빠르게 이동한다(잔상 모션, 효과음). 대시하는 동안은 탄·레이저·적 몸통에 피격되지 않는다. 쿨타임이 있고, 이동 입력이 없으면 발동하지 않으며, 대화 중에는 동작하지 않는다. 하단 안내에 `대시: X` 표시. 기본값(조정 가능): 지속 약 0.2초, 거리 약 120px, 쿨타임 약 1.5초.

**Blocked by:** 02 (X 키를 먼저 비워야 함)

**Status:** ready-for-agent

- [ ] 대시 중 탄/레이저/적 몸통에 맞지 않는다 (sim 테스트)
- [ ] 이동 방향으로 이동하고 판 경계를 넘지 않는다 (sim 테스트)
- [ ] 쿨타임 중 재발동 불가, 입력 없으면 발동 안 함 (sim 테스트)
