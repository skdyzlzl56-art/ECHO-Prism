# 05: X로 대화 빨리 출력

**What to build:** 대화 중 X를 누르고 있는 동안 글자가 빠르게 출력된다. 스킵과 달리 대사가 넘어가지는 않는다(다음 대사로 진행은 기존 키 그대로). 전투 중 대화와 스토리 장면 대화 모두 적용. 전투 중 대화에서는 X가 대시로 동작하지 않는다.

**Blocked by:** 03 (X 키 역할 정리 후)

**Status:** ready-for-agent

- [ ] 대화 중 X를 누르면 타이핑 속도가 크게 빨라진다
- [ ] X만으로는 대사가 다음으로 넘어가지 않는다
- [ ] 전투 대화/스토리 대화 모두 동작한다
- [ ] 대화 중 X가 대시를 발동하지 않는다
- [ ] `npm test` 통과
