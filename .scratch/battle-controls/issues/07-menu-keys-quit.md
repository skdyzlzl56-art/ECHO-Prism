# 07: C키 메뉴창 (키 설정, 종료)

**What to build:** 전투 중이나 대화창에서 C를 누르면 메뉴창이 열리고, 다시 C(또는 닫기)를 누르면 닫힌다. 메뉴가 열려 있는 동안 전투와 대화는 일시정지된다. 메뉴에는 지금 단계에서 **키 설정**과 **종료**만 있다. 키 설정에서는 이동 외 조작(사격 토글, 교대, 대시, 대화 빨리 출력)의 키를 바꿀 수 있고, 바꾼 키는 조작 안내 문구에도 반영된다. 종료는 확인을 거쳐 타이틀로 돌아간다. 메뉴 항목은 이후 티켓이 추가할 수 있게 목록 형태로 둔다.

**Blocked by:** 03 (대시), 05 (대화 빨리 출력): 설정할 조작이 모두 존재한 뒤

**Status:** resolved

- [ ] 전투 중과 대화 중 모두 C로 메뉴가 열리고 닫힌다
- [ ] 메뉴가 열려 있는 동안 전투/대화 진행과 탄이 멈춘다
- [ ] 키 설정으로 키를 바꾸면 즉시 적용되고 중복 키는 막는다
- [ ] 바꾼 키가 조작 안내 문구에 보인다
- [ ] 종료는 확인 후 타이틀로 돌아간다
- [ ] `npm test` 통과
