# 09: 메뉴에 저장/불러오기

**What to build:** C 메뉴에서 현재 진행 상황을 저장하고, 나중에 불러와 이어서 할 수 있다. 저장 대상은 진행 중인 스테이지/장면, 유대 레벨, 레벨·경험치(06)다. 전투 도중 저장은 해당 전투의 처음부터 다시 시작하는 지점으로 저장한다. 슬롯은 1개로 시작한다.

**Blocked by:** 07, 06

**Status:** resolved

- [ ] 저장 후 새로고침하고 불러오면 같은 장면에서 시작한다
- [ ] 유대 레벨과 레벨·경험치가 복원된다
- [ ] 전투 도중 저장하면 그 전투 시작 지점에서 이어진다
- [ ] 저장 데이터가 없을 때 불러오기는 안내만 하고 아무것도 바꾸지 않는다
- [ ] `npm test` 통과
