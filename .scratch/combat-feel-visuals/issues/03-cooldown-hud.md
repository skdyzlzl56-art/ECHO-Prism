# 03: 쿨타임 HUD

**What to build:** 대시, 회복, 방패의 쿨타임이 화면에 표시된다. 쿨타임은 동료별로 따로 관리되어, 교대해 곁에 없는 동료의 쿨타임도 내부적으로 계속 흐른다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 대시 쿨타임 표시
- [ ] 회복과 방패 쿨타임 표시
- [ ] 동료 교대 후에도 이전 동료의 쿨타임이 계속 줄어든다(테스트)
- [ ] 교대로 쿨타임이 초기화되거나 멈추지 않는다
- [ ] npm test 통과
