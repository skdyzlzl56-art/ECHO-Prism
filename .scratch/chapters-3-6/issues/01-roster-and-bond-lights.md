# 01: 동료 4명 순환 교대와 동료별 유대의 빛

**What to build:** X키로 동료 N명(최대 4)을 순환 교대하고, 동료마다 서로 다른 유대의 빛 효과가 나온다. 스테이지 1·2의 전투 동작은 바뀌지 않는다. 선행 정리 티켓.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 동료 목록이 4명이어도 X키가 순서대로 순환하고 쿨타임이 유지된다
- [ ] 유대 레벨(상한 4)과 게이지가 교대해도 하나의 값으로 이어진다
- [ ] 동료별 유대의 빛 효과를 전투 설정으로 지정할 수 있다 (루미=회복, 헥사=방패 유지)
- [ ] 스테이지 1·2 전투와 기존 `sim.test.js` 전부 통과
- [ ] 헤드리스 시뮬레이션 테스트가 3명 이상 순환 교대를 검증한다
