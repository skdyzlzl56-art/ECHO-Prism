# 챕터 3~6 직접 플레이 체크리스트

자동 테스트(`node --test`, 57개)는 규칙·데이터만 검증한다. 아래는 브라우저에서 눈과 귀로만 확인되는 항목이다. `webgame/index.html`을 열어 플레이하며 체크한다.

## 1. 가림·가시성 (occlusion / visibility)
- [ ] 대사창·초상화가 전투 박스, 적, 탄을 가리지 않는가 (특히 챕터 6 결전, 화면이 좁을 때)
- [ ] 이름이 적힌 탄(방향 규칙 「책」「이름」, 챕터 5·6)의 글자가 탄에 그려지고 읽히는가. 탄 색·배경과 겹쳐 안 보이지 않는가
- [ ] 색 규칙(챕터 3·6): 붉은 탄(#ff4d6d)과 다른 색 탄이 한눈에 구분되는가. **화면에 규칙 힌트가 없다** (대사로만 설명) -> 대사만 듣고 이해되는가, 힌트 UI가 필요한가
- [ ] 되감기(챕터 4·6): 되감기 순간 효과(rewind fx)가 보이는가, 탄이 튀는 것이 읽히는가
- [ ] 합동 유대의 빛(챕터 6): 빛 효과(joint light fx)와 소리가 나오고, 효과가 탄·플레이어 점을 가려 불공정하게 느껴지지 않는가
- [ ] 동료 4명(PARTY4)과 보스 몸체가 겹치지 않는가, 동료 모습이 판정 점을 가리지 않는가
- [ ] 장면 전환(미술관/시계탑/도서관/코어 배경)에서 초상화·텍스트 대비가 충분한가

## 2. 음악 취향 (s3~s6 트랙은 아직 아무도 듣지 않음)
각 트랙을 끝까지 듣고 분위기·반복 피로·볼륨 균형(대사 blip 대비)을 적는다.
- [ ] s3_field / s3_boss (미술관)
- [ ] s4_field / s4_boss (시계탑)
- [ ] s5_field (느린 첼로+하프) / s5_boss (합창 신스)
- [ ] s6_field (모티프 재현) / s6_boss (마지막에 D 단조로 해결)
- [ ] 전투 전환 시 bgm 끊김/겹침이 없는가, 보스전 후 필드 곡으로 자연스럽게 돌아오는가
- [ ] 메모: 마음에 안 드는 곡은 `music/`에서 재생성 요청

## 3. 난이도 (규칙별)
각 전투를 처음 / 두 번째 시도로 해 보고 체감 난이도(쉬움/적당/어려움)와 HP 손실을 적는다.
- [ ] 챕터 3 얼룩 전투 / 색 규칙 얼룩(playerHp 22) / 화가 보스(RED, playerHp 26): 맞지 않는 색을 무시해도 되는 것이 직관적인가
- [ ] 챕터 4 째깍이(rewind 5) / 시계지기 보스 / 탈출 전투(PARTY4): 5초 주기 되감기가 예측 가능한가
- [ ] 챕터 5 방향 규칙 쪽지(playerHp 22) / 사서 보스(playerHp 28): "탄과 같은 방향으로 움직이기"가 이해되고 실행 가능한가
- [ ] 챕터 6 페이즈별 규칙(색 -> 되감기 -> 방향 -> 색+되감기 -> 마지막 합동 빛): 규칙이 바뀔 때 전환 안내가 충분한가, 4·5페이즈가 지나치게 어렵지 않은가
- [ ] 마지막 페이즈: 공격이 0이라는 것을 플레이어가 알아채는가, 유대 가득 채우는 방법(그레이즈)이 전달되는가
- [ ] 유대 레벨이 스테이지를 넘어 이어지는 것이 난이도 곡선에 맞는가 (너무 일찍 Lv.4가 되지 않는가)

## 4. 브라우저에서 아직 확인 안 된 항목
- [ ] 합동 유대의 빛 연출 (`jointLight` 이벤트 -> 그리기+소리)
- [ ] 되감기 연출 (`rewind` 이벤트 -> 효과)
- [ ] 이름 적힌 탄(named bullet) 그리기
- [ ] 엔딩 카드 -> `s6_title` -> 클릭/SPACE/Z로 타이틀 복귀 (새로 불러오기), 복귀 후 처음부터 다시 플레이 가능
- [ ] 동료 4명 X키 순환: 루미 -> 헥사 -> 글리치 -> 시계지기 -> 루미, 쿨타임 1.5초, 시계의 빛 후 쿨타임 즉시 0
- [ ] 색 규칙은 화면 힌트 없음 (위 1번 항목과 동일, 의도된 것인지 결정)
- [ ] 마지막 한 줄(개체) 이름 표시가 "에코"로 나오고 blip 440Hz가 어색하지 않은가
