# 02: 부술 수 있는 탄

**What to build:** 내 탄과 동료 탄에 맞으면 체력이 깎이고 부서지는 큰 탄(h.breakable). 부수지 않으면 계속 위협이 된다. 부서질 때 이벤트와 효과음이 나온다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 플레이어/동료 탄에 맞으면 체력이 깎이고 0이면 사라진다 (sim 테스트)
- [ ] 부서지는 탄은 겉모습으로 구분된다
- [ ] 설정에 쓰지 않은 전투는 그대로다
- [ ] `npm test` 통과
